# MyTopDownGame — 项目思维导图

> Godot 4.7 · 俯视角射击游戏 · 640×360 视口(拉伸至 1920×1080) · Mobile 渲染 + Jolt 物理

## 🖥 工程配置 (project.godot)
- **主场景**：MainMenu（`uid://ctq8h0cdparas`）
- **渲染**：Mobile 渲染器 / D3D12 / 像素风贴图过滤(Nearest)
- **物理**：Jolt Physics
- **输入映射**：WASD → move_up / move_down / move_left / move_right

## 🔧 全局单例 Autoloads（启动即常驻）
- **Global** — 全局设置存档：music / sfx / fullscreen，读写 `user://save.json`
- **EventBus** — 事件总线（跨场景解耦信号）
  - 现有信号：`on_player_health_update(current, max)`
- **Transition** — 场景切换器：shader 进度 0→1 渐变后 `change_scene_to_file()`
- **Music** — 背景音乐播放器（Music 总线，-10dB 自动播放）

## 📦 数据层 Data/（Resource 数据驱动）
- **player/play_data.gd → `PlayerData`**：icon / id / max_hp / move_speed / magic
  - `player_bunny.tres` 兔子 · 默认值(HP5 速度200)
  - `player_cat.tres` 猫 · HP15 速度250
  - `player_dog.tres` 狗 · HP8 速度230 ← **竞技场当前使用的角色**
  - `player_mouse.tres` 鼠 · HP10 速度220
- **Weapons/weapon_data.gd → `WeaponData`**：icon / weapon_name / scene / damage / cooldown / mana_cost / spread / bullet_speed / bullet_scene / description
  - `weapon_pistol.tres` 手枪：伤害1 / 冷却0.4s / 耗蓝1 / 扩散7° / 弹速250

## 🎬 场景层 Scenes/
- **ui/main_menu** — 主菜单 + 设置面板
  - PLAY（→角色选择）/ SETTINGS（音乐·SFX·全屏 开关，按钮滑入动画）/ QUIT（存档退出）
  - 背景滚动 shader、按钮音效、tween 动画
- **character_selection** — 角色选择（**空场景，待开发**）
- **Arena/arena.gd/.tscn** — 竞技场
  - Node2D 根节点 + UI(CanvasLayer)：角色头像、血条、蓝条（TextureProgressBar）
  - 监听 `EventBus.on_player_health_update` 刷新血条
  - 直接实例化 `player_dog.tscn`
- **player/**
  - `player.gd` → `Player`（CharacterBody2D）：WASD 移动、idle/move 动画、受伤闪避、死亡销毁
  - `player_base.tscn` — 基础骨架：Visuals(Shadow+AnimatedSprite2D) / CollisionShape2D / Camera2D / HealthComponent / WeaponController
  - `player_dog/cat/bunny/mouse.tscn` — 角色变体：继承 base + 各自的 SpriteFrames / 碰撞半径 / 数据
  - `weapon_controller.gd` → `WeaponController`：手持武器节点，每帧朝向鼠标（`pivot.look_at`）
- **Components/health_component** → `HealthComponent`（可复用组件）
  - `initHealth` / `take_damage` / `heal` / `die`
  - 信号：`on_unit_damaged` / `on_unit_healed` / `on_unit_dead`
- **Weapons/**
  - `weapon.gd` → `Weapon`（基类）：pivot 节点 + `use_weapon()`（未实现）
  - `weapon_range.gd` → `WeaponRange`（远程武器）：sprite 朝向鼠标 flip_v
  - `weapon_range_base.tscn`：Pivot / Sprite2D / Marker2D(枪口) / ShootSound
  - `weapon_range_pistol.tscn`：手枪实例（基础数据已配好，开火逻辑待写）

## 🎨 着色器 Shaders/
- **background.gdshader** — 背景 UV 滚动动画（speed 参数）
- **transition.gdshader** — 钻石像素网格过渡（progress 0→1，Transition 使用）

## 📁 资源 Assets
- **Sprites/** — 玩家/敌人(史莱姆)/武器/物品(Item_White1-18)/UI 图集（tilemap_packed.png、bar_health/mana 等）
- **Sounds/** — BGM(mp3) + 几十个 OGG 音效：shoot / hurt / coin / jump / explode / select 等
- **Font/** — Comicoro.ttf、Lilian.ttf、font_game.png
- **Extra/** — font_16.tres / font_48.tres 字体预设

## 🔄 游戏流程与数据流
```
MainMenu ──PLAY──▶ CharacterSelection ──选择──▶ Arena
   │                    (待开发)                │
   └── Transition 渐变切换 ──────────────────────┘
```
- **数据流**：PlayerData → player.tscn → Player 节点 → HealthComponent → EventBus 信号 → Arena UI 血条
- **待办/下一步**：角色选择场景、武器开火(`use_weapon`)、子弹/敌人、蓝条逻辑

## 🧩 架构模式小结
| 模式 | 体现 |
|------|------|
| 数据驱动 | Resource(.tres) 定义角色/武器属性，场景引用 |
| 组件化 | HealthComponent 独立复用，信号解耦 |
| 继承 | Weapon←WeaponRange；PlayerBase←4角色 |
| 事件总线 | EventBus 跨场景通信（UI↔游戏逻辑） |
| 全局单例 | 设置/过渡/音乐常驻，全局可达 |
